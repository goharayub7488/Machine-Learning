# User Data Analysis

## This project performs exploratory data analysis (EDA) on a user dataset to understand demographic patterns such as age distribution, gender distribution, and occupation trends.

## Dataset

### The dataset contains information about users including:

- Age
- Gender
- Occupation
- Zip Code

### Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning

### The following preprocessing steps were performed:

- Checked for missing values
- Removed duplicate rows
- Converted column names to lowercase

## Feature Engineering

### Created a new column **age_group** using `pd.cut()`.

### Age groups:

- 0–18 → Teen
- 19–35 → Young Adult
- 36–50 → Adult
- 50+ → Senior

## Data Analysis

### The analysis includes:

- Average age of users
- Gender distribution
- Most common occupation
- Average age by occupation
- Youngest and oldest user

## Visualizations

### The following charts were created:

- Age distribution
- Gender distribution
- Top 10 occupations

## Insights

### Most users fall in the **Young Adult** age group.

### The most common occupation is **Student**.

### Male users are more frequent than female users.
